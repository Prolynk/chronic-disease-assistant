# Chronic Disease Self-Management Assistant

MSc AI Dissertation Demo, Strategy 1: Dense Retrieval
**Habeeb Adekeye | KF7029 | Northumbria University**

## About

This is a research prototype demonstrating Strategy 1
(dense retrieval RAG) of a three-strategy comparison
for chronic disease self-management chatbots.

The assistant retrieves evidence from:
- ADA Standards of Care 2026 (Diabetes)
- AHA/ACC Hypertension Guidelines 2025
- GINA Asthma Strategy Report 2026

## Disclaimer

This tool is a research prototype for dissertation
demonstration only. It is not intended for clinical
use. Always consult a qualified healthcare professional.

## Deployment

Hosted on Streamlit Community Cloud (share.streamlit.io).
Main file: `app.py`. Requires an `OPENAI_API_KEY` secret
set in the app's Settings, no other configuration needed.
